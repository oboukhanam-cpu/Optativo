## Cómo abrir la página

Clona el repositorio con `git clone https://github.com/oboukhanam-cpu/Optativo.git` y abre `index.html` en el navegador.

## Estructura

- `index.html` contiene la página.
- `.gitignore` excluye las carpetas de configuración de los editores.

## Mejoras

- Tabla con las tareas del proyecto y la herramienta que se usa en cada una.
- Menú con enlaces al inicio y a la tabla de tareas.
